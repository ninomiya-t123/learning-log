# DOM

概要
- Document Object Modelの略  
- HTMLを木構造で表現したもの

特徴
- 要素変更時に全体再描画が発生しやすい
- レンダリングコストが高い
- コードが複雑化しやすい


# 仮想DOM

概要
- JavaScriptオブジェクトで表現された仮想的なDOM

特徴
- 差分のみを実DOMに反映
- パフォーマンスが高い

使用例
- React
- Vue

ひとこと理解<br>
DOMを直接いじる前に、仮想的に比較して必要箇所だけ更新する仕組み



# DOM vs 仮想DOM

| 項目 | DOM | 仮想DOM |
|------|-----|--------|
| 更新方法 | 全体 | 差分 |
| パフォーマンス | 低い | 高い |
